# Moon & Sun Theme Toggle 🌙☀️

A beautiful animated theme button changer that shows a **Moon** in dark mode and a **Sun** in light mode, with smooth transitions and a premium look.

## Features

- Smooth animated switch between Moon (dark) and Sun (light)
- Works offline (Tweakpane is optional)
- Modern CSS (Cascade Layers, `light-dark()`, etc.)
- Fully accessible (`aria-pressed`)
- Clean and responsive design
